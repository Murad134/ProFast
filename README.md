## 📌 Project Overview

**Send Parcel** is a **MERN Stack Parcel Delivery Management System** designed to manage parcel booking, rider assignment, payment processing, and delivery tracking across all 64 districts of Bangladesh.  

Supports **User**, **Rider**, and **Admin** roles with secure authentication, Stripe payment integration, and district-based rider assignment.

# 🧩 Features

## 👤 User Features

- Register & Login (Email validation & verification)
- Role-based access control
- Create Parcel
- Pay via **Visa Card (Stripe Integration)**
- View own parcel list
- View own payment history
- Request to become a Rider

---

## 🛵 Rider Features

- Create Parcel
- Pay via Stripe
- View own parcels
- View own payment history
- View pending parcels (own)
- View completed parcels (own)
- View My Earnings

---

## 👨‍💼 Admin Features

- Create Parcel
- Assign Rider based on District
- Approve Rider Requests
- View Active Riders
- Create Another Admin
- View All Parcels
- View Payment History
